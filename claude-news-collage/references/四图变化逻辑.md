# 四图变化逻辑（参考组：票务平台退票）

参考图：`变化逻辑参考/图1.webp` – `图4.webp`。

学的是**变化方式**，不是具体内容。不要照抄这几张图里的楼、人群或配色。

## 四张图各自做了什么

| 图 | 景别 | 底色 | 信息重点 | 主要物件 |
|----|------|------|----------|----------|
| 1 | 全景 | 橙 | 新闻主体是谁：票务平台 | 现代大楼 + “票务平台”招牌 + 排队人群 |
| 2 | 特写 | **换成芥末黄** | 关键说法：“特殊商品” | 只剩一张超大门票，四周大量留色 |
| 3 | 中景 | 朱红 | 行为：拿它当借口挡回退票 | 售票厅正立面 + 手递门票 + 退回标志 |
| 4 | 全景 | 亮橙 | 结果：借口被否定，退票通道打开 | 圆形场馆 + 红叉 + 青绿出口箭头 |

## 变化规律

1. **景别跳变**：全景 → 特写 → 中景 → 全景。相邻两张不用同一景别，特写负责把一个关键词或关键物件“钉”在观众眼前。
2. **重点转移**：每张图只回答一个问题（谁 → 什么说法 → 做了什么 → 结果如何），上一张的主角可以在下一张完全消失。
3. **主体可以换造型**：四张图里“票务平台”分别是商场大楼、古典售票厅、圆形场馆。造型不用一致，只要每次都能一眼认出是“售票的地方”。
4. **贯穿线索**：真正把四张串起来的是反复出现的符号，而不是同一栋楼：
   - “特殊商品”门票：图2 主角 → 图3 被递进窗口 → 图4 变成挂在门边的竖条标签
   - 掉头箭头：图3 红色退回标志 → 图4 拱门上的青绿掉头箭头 + 出口箭头
   - 门票形状：四张图里都有（图标、海报、窗格、大门票）
5. **风格统一**：同一套黑白半调照片剪纸、奶油白描边、撕纸边、角落网点碎片、橙 / 红 / 黄 / 青绿卡纸。底色可以换，但都在同一个暖色系里，中间用一张反差色（黄）做强调。
6. **顶部照常铺满**：背景、场景和纸片一直延伸到顶边，只是人脸、关键标签和结果不放在顶部；主体放在中部到中下部，四角用撕纸碎片填满。

## 写进 image-plan 的方式

- 变化逻辑只体现在四条 `frames[n].prompt` 正文里：每条写清本图景别、主体、重点、底色和中文标签。
- 贯穿线索（如“特殊商品”门票）在需要它的几张图里分别写明，可以改变大小和用法；不要用跨图锁定语句。
- 视频参数 `scene / objects / action / result / palette` 仍按原项目规则写共用摘要，不受这里影响。

`examples/票务平台退票/image-plan.json` 是按这组图的变化方式写的完整示例。
